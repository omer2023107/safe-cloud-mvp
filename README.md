# SAFE CLOUD — الإدارة الذكية وأمن الحوسبة السحابية

نموذج أولي تفاعلي (`Prototype`) ضمن **هاكاثون شراع 2026 للذكاء الاصطناعي العربي** (فريق وحدة الظل السيبرانية).

## المكونات الرئيسية
- **الفحص الأمني الموحد:** التحقق من صيغة `JSON`، وتطبيق 8 قواعد فحص ثابتة، وترتيب الأولويات (`P1/P2/P3`) مع وضع `Fallback`.
- **المراقبة المستمرة 24/7 والتنبؤ:** مراقبة لخادم محدد أو لجميع الخوادم مع إنذار مبكر ووكلاء ذكاء اصطناعي مقيدين بصمام أمان إلزامي.
- **الصلاحيات والمصادقة (`RBAC`):** دعم الأدوار الأربعة مع لوحة تسجيل دخول وإنشاء حساب (Email / GitHub / Microsoft / Google).
